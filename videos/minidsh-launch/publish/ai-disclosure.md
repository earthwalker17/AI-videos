# AI use

- **What AI did.** An AI coding agent (Claude Code, Claude Opus 5.5) did the following under the
  creator's direction:
  - wrote and revised the code that makes the picture and the score: the capture tools, the
    renderer, the staging of the captures, the type, the camera, the on-screen words (the cue
    sheet; the creator chose the desktop title's wording at the review) and the music;
  - drove the live product sessions: its scripts typed the task and the follow-up, clicked Allow
    once, and quit the desktop app mid-turn; it chose the stills;
  - wrote three treatment candidates and recommended one;
  - checked every claim against MiniDSH's sources ([FACTS.md](../FACTS.md)) and drafted the
    captions and the publish texts (title, description, the X and Product Hunt posts) for the
    creator to edit.

  Agent reviewers (frame critics, first-time viewers with no context, facts and publish auditors)
  checked the cut and the texts; their findings were fixed or shown to the creator.
- **The product on screen.** Every pane is real MiniDSH 2.0.0 output. The web UI and the desktop
  app are real captured stills; the terminal is redrawn by the film's code from its recorded
  output, in the film's type and colours. The text the agent writes inside it (its replies, its
  reasons) comes from the model MiniDSH called, DeepSeek (deepseek-flash), unedited. The film's
  own additions are the pointer, the pressed light on Allow once, the red on the desktop close
  button, and the generic browser frame around the web UI. It shortens waits and never changes a
  state.
- **What the creator did:**
  - made MiniDSH: its architecture, direction and review (coding-agent sessions wrote nearly all
    of its code against an architecture written down first, as its README and case study say);
  - chose the subject, the brief, the treatment, the capture plan, the panes' theme and the text
    size at the look check;
  - decided at every approval gate (treatment, review cut, final).
- **What no AI did.** No generative image, video, music or voice model made any of the film. Every
  sound is synthesised by code.
- **The thumbnail:** recorded here when it is added (see the release routine). Any product UI in
  it is a real capture; generative AI only for backgrounds (the series rule).
- **YouTube's "altered or synthetic content" setting** (Studio, "AI use"): the film shows real
  software and abstract animation, with no realistic person, place or event; shortening waits is
  editing and changes no state. So the setting is not required for the picture. Whether YouTube's
  note on AI-generated music covers a score that an AI agent wrote as code is unclear
  (references/youtube-publishing.md); the creator makes that call at upload.
