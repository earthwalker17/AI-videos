# 万圣节礼物

万圣节之夜，Clawd 带着礼物，去敲最后一户还亮着灯的人家。一分钟的绘本短片：书桌上的一本书猛然
翻开，月光下的墓园、歪斜的铁门和吊着的幽灵从书页里长了出来，而这份礼物原来是……一封邮件。

画面和配乐全部由代码生成：用 Remotion 与 React Three Fiber 程序化搭建的三维世界，用 TypeScript
合成的原创圆舞曲与音效。源代码、工作流程和每一步渲染：
https://github.com/earthwalker17/AI-videos/tree/main/videos/halloween-gift

（公有领域）；字体 IM Fell English、Noto Serif SC 与 Inter（OFL）。使用 Claude Code 制作。
