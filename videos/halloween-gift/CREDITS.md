# Credits: A Halloween Gift

Everything in the picture is built by code in `src/`: procedural 3D geometry (the terrain,
trees, stones, iron, roofs, pumpkins, the book, the characters), shaders, and textures drawn on
canvases at render time. There are no image, texture or model files. The score and sound
effects are composed and synthesised by code in `audio/`.

## Tools
Remotion 4.0.539 (Remotion License), three.js 0.186.1 (MIT), React Three Fiber 9.8.2 (MIT),
postprocessing 6.39.5 (Zlib), FFmpeg 8 (LGPL/GPL build, used as a tool), Node 24 and the
repository's own pipeline (render, audio, post, QA). Made with Claude Code. No generative
image, video, music or voice models were used in the film; the YouTube thumbnail was generated
with ChatGPT (see above).
