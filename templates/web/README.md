# Web template

A runnable scaffold for the [web engine](../../engines/web/ENGINE.md). It is also that
engine's end-to-end fixture: `aiv render template:web` runs the whole pipeline on it.

## What it shows

The clip is 5 s at 30 fps (150 frames), 1920x1080 at the `review`/`final` profiles.
- **Frames 0-14: a test card.**
  - The colour swatch strip (`TEST_SWATCHES` at `swatchLayout(w, h)` from `@aiv/core`).
    `aiv qa` decodes these frames from the final mp4 and checks each patch within ±3 code
    values (`video.json` `qa.swatchFrames`).
  - A grey ramp, crop marks in every corner, and a circle that shows a wrong aspect ratio
    at a glance.
- **Frames 15-149: a three.js scene.**
  - A WebGL lit, shadowed gold torus knot with image-based light.
  - A seeded scatter of 160 shapes; every property is `rand(seed, k, property)`.
  - A camera orbit eased with `progress(i, …, 'inOutCubic')`.
  - On top, a Canvas 2D layer: a title in Inter, a progress bar, a frame counter.
- **Audio:** a quiet A-major sine chord plus seeded pink noise, both generated by ffmpeg
  (`lavfi:` tracks) with fades. `aiv post` masters it to -14 LUFS.

Everything is sized from the frame size the harness passes in the URL (`pageParams()`),
and every frame is a pure function of its index.

| File | What |
|---|---|
| `video.json` | Engine, entry, format, audio tracks, QA settings. |
| `src/index.html` | The page the engine opens. |
| `src/main.ts` | Boot: the output canvas, font loading, `installCapture`. |
| `src/scene.ts` | The three.js layer. |
| `src/card.ts` | The test card and the title overlay (Canvas 2D). |

## Render it

```sh
pnpm aiv doctor --fix                          # once: the pinned browser (~440 MB on disk)
pnpm aiv render template:web --profile draft   # 960x540, about 20 s on the reference laptop
pnpm aiv post   template:web --profile draft
pnpm aiv qa     template:web --profile draft   # then look at out/_template-web/qa/draft/contact.png
```

`--profile final` renders 1920x1080, encodes the YouTube delivery plus the archive master,
and allows `aiv release template:web`. Output goes to `out/_template-web/`, so it never
collides with a real video.

## Start a video from it

`aiv new <slug> --engine web` copies this folder to `videos/<slug>/`, writes its
`video.json` and the stage documents. Then:
1. Replace `src/scene.ts` (the 3D scene: `PALETTE` for the scattered shapes, the hero's and
   the ground's material colours, the lights, the background and fog) and the overlay in `src/card.ts` (`drawOverlay`: title, subtitle, progress
   bar, frame counter) with your own. The test card's label (`drawCard`) and the page
   `<title>` in `src/index.html` still name the template.
2. Keep the test card frames, or move the strip: `swatchFrames` in `src/main.ts` and
   `qa.swatchFrames` in `video.json` must name the same frames, `[start, end)` with the end
   excluded (the engine refuses to render otherwise). QA checks the first, middle and last
   frame of that range. Without a strip QA records colour as NOT VERIFIED.
3. Replace the `lavfi:` bed with your audio.
4. Run `pnpm lint` after editing `src/`: the determinism rules are ESLint rules.

The template has no `package.json`. `three`, `@aiv/core`, `@aiv/engine-web/page` and
`@fontsource-variable/inter` resolve from the repository root, pinned by the lockfile.
